# iRideAlong

Mitfahrgelegenheits-App aus dem Kurs **Software Engineering**, WS 2016/17.
Gruppenarbeit (Team robojophi).

**Stack:** Meteor.js, Angular 2, Cordova (iOS/Android)

## Inhalt

- `iRideAlong/` — Meteor-App (client, server, public, mobile-config)
- `Angular2Templates/` — Angular 2 Komponenten-Templates (component, directive, pipe, service)

## Features

- Echtzeit-Mitfahrangebote (Meteor reaktive Daten)
- Mobile-App via Cordova
- Geofencing-Integration (`cordova-plugin-geofence`)
