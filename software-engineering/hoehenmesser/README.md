# Höhenmesser

Android-App zur GPS-basierten Höhenmessung. Projekt aus dem Kurs **Software Engineering**, Beuth Hochschule für Technik Berlin. Einzelarbeit.

**Stack:** Android (Java), Gradle

## Inhalt

- `app/src/` — Android-Quellcode (MainActivity, GPSTracker)
- `altimeter.apk` — Kompilierte App (installierbar auf Android)

## Features

- GPS-Standortabfrage via `GPSTracker`
- Anzeige von Breitengrad, Längengrad und Höhe
- Höhenverlauf-Liste (ArrayList)
- Android 6+ Runtime-Permissions
