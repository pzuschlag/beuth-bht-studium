# WebGL-Setup-Test

Kleines Testprogramm zum Aufsetzen der WebGL-Rendering-Pipeline (Kontext-Erzeugung, einfache
Szene, Interaktion per Maus-Dragging) — Vorstufe zu den eigentlichen Canvas/Surfaces-Übungen.

`index.html` im Browser öffnen. `webgl-demo.js` initialisiert den WebGL-Kontext, `scene.js` und
`dragger.js` steuern Szene und Maus-Interaktion, `vec2.js` liefert die 2D-Vektormathematik.
