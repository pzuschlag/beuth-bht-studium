# CG2 A2 — WebGL / Surfaces (Basisversion)

Übungsblatt 2: 3D-Rendering mit WebGL. Ein Robot-Modell (`models/robot.js`) wird per
Vertex-Color-Shader (`shaders/vertex_color.vs`) gerendert, dazu eine einfache Sound-Anbindung
(`sounds/`) und ein Buffer-Geometry-Aufbau (`scene/buffer_geometry.js`) für die Geometriedaten.

`index.html` im Browser öffnen. Siehe auch [`../ue-03-surfaces/`](../ue-03-surfaces/) für die
erweiterte Fassung mit Phong-Shading, Explosion-Effekt und Rauschtexturen.
