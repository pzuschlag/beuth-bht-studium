# CG2 A1 — Points, Lines, Curves & Canvas

Übungsblatt 1: 2D-Rendering auf dem HTML5-Canvas.

- **Kd-Tree** (`kdtree/`) zur räumlichen Indizierung von Punkten (Nearest-Neighbour-Suche)
- **Bézierkurven** (`scene/bezier_curve.js`) inkl. interaktiver Kontrollpunkte
- **Szenegraph** (`scene/`) für Punkte, Linien und Kurven als eigenständige Objekte
- **HTML-Controller** (`controller/html_controller.js`) verbindet UI-Elemente mit der Szene

`index.html` im Browser öffnen, `app.js` ist der Einstiegspunkt.
