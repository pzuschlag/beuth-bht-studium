# Waschmaschinen-Raytracer

Java-Raytracer aus dem Kurs **Computergrafik 2**, WS 2016/17. Gruppenarbeit (Team Waschmaschine).

**Stack:** Java

## Was der Raytracer kann

- Geometrien: Kugel, Ebene, Dreiecke (`src/geometries/`)
- Kamera-Modell, Strahlen-Berechnung (`src/camera/`)
- Farb- und Beleuchtungsmodell (`src/color/`)
- Matrizen/Vektoren-Bibliothek (`src/Matrizen_Vektoren_Bibliothek/`)
- Render-Output als Bilddatei

## Materialien

- `Screenshots/` — gerenderte Ergebnisbilder
- `Texturen/` — verwendete Textur-Dateien
- `Dokumentationen/` — Team-Protokolle (UE 02–05)
