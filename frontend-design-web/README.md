# Frontend Design Web

Übungen aus dem Kurs **Frontend-Design-Web**, Beuth Hochschule Berlin.

**Stack:** HTML5, CSS3, SASS

## Inhalt

Aufgaben 01–11 zu HTML5-Semantik, CSS3 (Selektoren, Box-Model, Flex, Grid, Shapes, Transform/Transition/Animation) und SASS (Variablen, Mixins, Loops, Conditions).
